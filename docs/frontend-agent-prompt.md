# 前端重写交接 prompt

请从零重写 `YChen0317/Mechrevo-Control` 的 Windows 前端。以 `integration/windows-v1` 为起点开新分支，先读 `docs/frontend-handoff.md`、`contracts/v1.json` 和 `backend/README.md`。你负责新前端的技术选型、界面、托盘、OSD 和可运行包。旧前端已从这个分支移除，可以自行选择技术栈和目录。

直接接入已实机验证的 0.3.1 后端。普通权限前端连接本机命名管道 `Mechrevo.Control.v1`，先做状态读取和订阅，再接平衡、性能两档切换。切档等固件读回再更新界面，断线时标记旧快照，重连后刷新状态。控件按能力开放，未知读数和零值分开显示。演示要单独启动并明确标注。

首版做简体中文的主窗口、托盘和可开关的本应用 OSD。主窗口至少显示当前档位、供电、电量、充电状态和 CPU 封装功耗。触摸板与键盘背光提示已有实机证据，麦克风和刷新率按键状态未知时按未知显示。遇到协议不一致，带着具体请求、回复和复现步骤跟后端协调。
