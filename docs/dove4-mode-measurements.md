# Dove4 插电两档对照

用户在原厂控制中心依次选择平衡、性能。两次均以同一段并行 CPU 运算运行 45 秒，每档取得 29 个有效 RAPL Package 功率样本。采集时 Windows 电源计划及有效 overlay GUID 相同，OEM 注册表 ModeSet 分别为 1 和 2。

| CPU 封装功耗 | 平衡 | 性能 |
|---|---:|---:|
| 全程样本平均 | 20.15 W | 21.26 W |
| 最后六个样本平均 | 16.82 W | 20.98 W |
| 采样最大值 | 22.81 W | 24.26 W |

每档只测一轮，依次测量，未控制起始温度。结果描述此次负载，无法据此确定固件 PL1、PL2 或持续时间。频率、风扇转速和温度未同步记录。测试中读取了原厂状态，未更改功率参数。

## 第二轮插电对照

管理员 Windows PowerShell 5.1，使用 Capture-Dove4Research.ps1 -Load，各 45 秒、21 个样本。两档均报告已接电、未充电。固件和注册表分别确认平衡 1、性能 2。

| 指标 | 平衡 | 性能 |
|---|---:|---:|
| CPU 封装功率平均 | 15.43 W | 15.52 W |
| CPU 封装功率采样峰值 | 16.26 W | 16.85 W |
| 最后五个样本功率平均 | 15.52 W | 15.80 W |
| 多数样本实际频率 | 约 3.92 GHz | 约 3.92 GHz |
| 风扇通道 1/2 原始值，负载前 | 3823 / 3692 | 3823 / 3717 |
| 风扇通道 1/2 原始值，负载中 | 3878 / 3698 | 3906 / 3717 |

平均功率相差约 0.08 W（0.53%）。两档都没有上报 Windows 处理器性能限制标志。ACPI 温区及 EC TSR4 读数在这一轮均未变化。由于没有同步取得经过校验的 CPU 封装温度或直接读取功耗配置，不能把本轮功率或风扇读数差异归因到固定 PL1/PL2 或散热曲线。第一轮测到更大的尾段差异，尚未在第二轮重复。两轮之间没有足够证据解释差异来源。

两路风扇、EC 温度和 USB-C VBUS 的固件方法成功返回。风扇换算单位、TSR4 对应传感器及 VBUS 量纲还待比对。两档 VBUS 返回十进制 200，充电模式和上下限字段均为 0。当前电量与停充阈值的关系未测，不能仅凭 Charging=False 确认限充。
